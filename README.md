> **Sample / demo project.** Not client work. The input contact list is generated by `make_messy.py` and every name and email is fictional.

Takes a messy contact list and cleans the names, emails, phone numbers and dates, drops blank rows and duplicates, and writes a clean CSV plus a before/after report.

![Before and after cleanup](screenshot.svg)

## The problem
Exports from forms, CRMs and old spreadsheets are full of inconsistencies: ALL CAPS names, emails with spaces or a comma instead of a dot, phones in six formats, and dates written every way possible. That breaks mail merges, imports and dedupes.

## Features
- **Names:** proper case, with handling for O'Brien, McDonald/MacLeod, hyphenated names and "van der".
- **Emails:** trims spaces, lowercases, fixes `,com`, and flags anything still invalid.
- **Phones:** normalizes US numbers to `(478) 555-0001`, strips a leading 1, blanks junk like "n/a".
- **Dates:** reads `3/4/2025`, `2025-03-04`, `04-Mar-2025` and `March 4, 2025`; outputs ISO `YYYY-MM-DD`.
- Drops blank rows and dedupes on the cleaned email.
- Writes `output/report.md` with counts and a before/after table.
- No third-party packages needed to run it (pytest only for tests).

## Quickstart
```bash
git clone https://github.com/Ashton-Standridge/csv-cleanup-demo.git
cd csv-cleanup-demo
python make_messy.py                         # creates samples/messy_contacts.csv
python clean.py samples/messy_contacts.csv   # -> output/clean_contacts.csv + output/report.md
```

## Project layout

## How this maps to client work
| If you need… | This demo shows… |
|---|---|
| A CRM or email-tool import that won't fail | Consistent names, emails, phones and dates |
| Duplicates merged out of a list | Dedupe on a normalized key |
| Proof of what changed | A before/after report with counts |
| A rule for your edge cases | Small, testable functions per field |

**Known limit:** name casing is rule-based, so "DeShawn" typed in all lowercase becomes "Deshawn". On a real job I'd keep an exceptions list, or leave names alone when they're already mixed case.
